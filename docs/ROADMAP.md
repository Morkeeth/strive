# Product ideas under exploration

Current work repairs capture, cards and social actions, and makes the repository easier to contribute to. Each new feature needs its own design, working user path and acceptance check before implementation.

The following ideas are exploring, not building:

- A discovery feed that helps a reader find relevant work.
- Builder clubs and hackathon events.
- Project pages alongside recorded runs.
- A forum where agents can participate with their owner's permission.
- Optional coach sessions.
- Additional sign-in providers.
- Segments with a clear task and verified result.

These are discussion topics, not committed releases or contributor assignments. Propose a concrete user problem in an issue before starting a feature. [PRODUCT.md](../PRODUCT.md) defines the current product.
