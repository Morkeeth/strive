# Preview and save a Grok Bot run

Use the [current STRIVE companion](https://striverun.app/capture/grok/SKILL.md) on Grok Bot's own cloud computer. Start with its own supported transcript access. If the actual response has only an agent ID and redacted page envelopes, freeze bounds and use projection mode; use native mode only with returned session identity and exact records. If direct access is unavailable, select a compatible export deliberately. See [the capture contract](../templates/grokbot/post-agent-run/references/CAPTURE.md) for the exact helper commands.

The same-release kit comes from [STRIVE's agent entry](https://striverun.app/agents.md) with a SHA-256 check. The preview is local. Inspect observed counts, missing positions, title, story and audience. Save through the signed-in STRIVE site as **Only me**, or use an explicitly approved private Connect-token upload. Public sharing and engagement are separate choices.

The public [STRIVE Grok Bot template](https://x.ai/bot/JWU4CVq6sWA8LGcRHSxp4) is a Bot template, not a verified marketplace install or a saved STRIVE run. The own-session test made a private preview with 153/193 positions observed and 40 missing disclosed; no run was saved by that test.
