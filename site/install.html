Install STRIVE

See what happened in a recorded coding session. Pick a session, open its private preview, then decide if you want to save a run.

The MCP server runs on your computer. It offers two tools: list_sessions and preview_session. Adding it does not upload or publish a run. You need uv and Python 3.9+.

Manual fallback

In Cursor, open Settings → Tools & MCP → Add custom MCP. Add this server to ~/.cursor/mcp.json:

{"mcpServers":{"strive":{"command":"uvx","args":["--from","__STRIVE_MCP_SPEC__","strive-mcp"]}}}

Want the full STRIVE skill?

The MCP server gives your agent a session list and a local preview. The separate STRIVE plugin adds the strive skill and optional local capture hook. Read the editor plugin instructions, including the ZIP fallback and version checksum.

What happens after install?

Ask your agent to list your recent sessions, pick one you recognise, and open its private preview. Review the card before saving. A saved run starts as Only me; you choose another audience separately.
